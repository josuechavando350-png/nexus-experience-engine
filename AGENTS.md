# Nexus Experience Engine Constitution

This repository stores structured creative knowledge. It is not a snippet library, a template catalog, or a place to reproduce third-party work.

## Principles

1. Mobile-first is mandatory.
2. Never clone complete layouts, assets, visual identity, or proprietary code from external references.
3. External references are used to study principles, techniques, and behaviors.
4. Every implementation accepted by Nexus must be original work.
5. Prioritize creative intent over ornamentation.
6. Animation without purpose is not an improvement.
7. Avoid common fingerprints of AI-generated sites.
8. Avoid repetitive layouts across projects.
9. Avoid excessive cards, generic grids, decorative numbering, and repeated CTA patterns.
10. Do not turn references into templates.
11. Treat mobile as its own experience, not as a reduced desktop layout.
12. Keep accessibility and performance as design constraints.
13. Every technically expensive capability requires a degradation strategy.
14. Keep the system modular.
15. Do not overengineer the MVP.

## Reference policy

The required workflow for any future reference analysis is:

> observe -> describe -> abstract -> reconstruct -> validate

Never use:

> see -> copy

Record observations as evidence, separate them from abstractions, and never store third-party source code or downloaded assets in a Genome entry.

## Scope discipline

- Genome entries describe reusable intent, mechanics, constraints, and validation evidence—not paste-ready snippets.
- New fields and modules require a concrete use case.
- Mobile behavior, accessibility, reduced motion, and fallback behavior are required parts of every technique.
- Prefer small, inspectable tools that can run in CI.
